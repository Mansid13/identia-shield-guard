# Identity Guardian

Build a web app called IDENTIA with the tagline "Connect the Identity.
Expose the Shadow." It helps people detect impersonation of their
online identity and collect evidence.

Design: modern and clean. Colours: deep navy #0F1B4C, plum #7B0F55,
teal #1A7A8C, amber #F2A93B, light background #F4F6FB. Rounded cards,
soft shadows, and a left sidebar for navigation.

Pages (use realistic fake data for now):
1. Landing page: the problem, how it works in 5 steps, a "Get started" button
2. Dashboard: counts of verified accounts, suspicious accounts, saved cases
3. Identity Core: list of verified accounts (Instagram, GitHub, LinkedIn)
   with an "Add account" button
4. Identity Graph: placeholder box
5. Shadow Check: placeholder form
6. Evidence Locker: list of saved cases

No login or database yet. Focus on making it look polished.
